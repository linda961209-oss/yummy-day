# 🍓 Yummy Day — 今天吃什麼？（一中街 × 逢甲夜市特別版）
> **大學「程式設計與應用」課程期末專案作品**  
> 一款結合「韓系奶油甜點店風 × 台中一中街與逢甲在地名店」的互動式美食選擇決策網站。

---

## 📖 專案背景與設計理念

每到用餐時刻，「今天吃什麼？」總是台中大學生最糾結的世紀難題！本專案鎖定台中最指標的兩大美食戰區：**「一中街夜市商圈」** 與 **「逢甲夜市商圈」**，建立專屬的 48 道在地名店美食資料庫。

網站採用「韓系奶油風 × 草莓甜點店」的精緻視覺美學，特別收錄學生熱烈討論的愛店，包含**圈粉舖子、私肉羹、50藍、逢甲激旨燒鳥串燒、酥立蛋餅、The bab韓式中友一中店、麥味登**等，打造兼具生活質感與實用決策的課堂代表作！

## 🎡 五大核心功能與實作

1. 🎡 **美食命運轉盤**：
   - 採用 HTML5 Canvas 搭配三次貝茲減速曲線物理旋轉。
   - 外圍繪製 32 顆精緻立體珍珠與金箔蕾絲環，搭配復古金邊心形寶石指針。
   - 支援前置篩選「一中商圈 / 逢甲夜市 / 異國人氣名店 / 甜蜜冰品 / 手搖特調」及預算。
   - **指針判定保證**：以 270° 正上方嚴謹推算角度，指針最後指向的項目與彈窗結果 100% 絕對一致！
2. 💗 **心情選食物**：
   - 6 種心情狀態（😄 開心、🥺 難過、🥱 疲倦、😫 壓力大、🙃 無聊、🥰 幸福）。
   - 壓力大推薦圈粉舖子酸辣粉、刁民酸菜魚；難過推薦私肉羹、熱甜點；疲倦推薦麥味登鐵板麵！每張卡片附有貼心推薦私房話。
3. 💰 **預算與商圈餐點篩選**：
   - 5 種預算區間（100元以下、101～200元、201～300元、301元以上、不限預算）。
   - 搭配餐點型態（飯類、麵類、炸物、串燒鍋物、蛋餅輕食、甜點、飲料）交叉過濾，並支援關鍵字即時搜尋與價格排序。
4. ❤️ **我的美食收藏清單**：
   - 每張卡片點擊愛心即時以 LocalStorage 持久化保存，網頁重整不遺失。
   - 導覽列即時同步更新數量徽章，提供分類過濾與一鍵清空功能。
5. 🍰 **今日幸運美食推薦**：
   - 每天依據本地日期雜湊（Deterministic Hash）自動推薦一款一中/逢甲幸運美食，同一天重整保持一致，隔天自動輪替。

## 🗂️ 檔案結構說明

```
yummy-day/
│
├── index.html          # 主頁面：語義化 HTML5、導覽列、拍立得拼貼、五大功能區與彈窗
├── css/
│   └── style.css       # 樣式表：韓系奶油風配色、法式甜點盤轉盤、菜單風卡片、跑馬燈
├── js/
│   ├── data.js         # 一中街與逢甲夜市 48 道名店資料庫 (含圈粉舖子、私肉羹、50藍等)
│   ├── wheel.js        # Canvas 命運轉盤類別 (FoodWheel)：物理減速、珍珠珠飾、指針判定
│   └── app.js          # 核心邏輯 (YummyApp)：SPA 頁籤切換、LocalStorage 收藏、音效與篩選
├── server.ps1          # 本機輕量 HTTP 靜態伺服器 (PowerShell 原生)
└── README.md           # 專案報告與課堂發表說明手冊
```
